# PowerBI-miniproject
✈️ Airline Passenger Satisfaction Analysis
📌 Project Overview

This project focuses on analyzing airline passenger satisfaction data using Microsoft Power BI. The objective is to understand passenger preferences, identify factors affecting satisfaction, and generate meaningful insights from customer service and flight-related data.

The dataset contains information about passenger demographics, travel details, flight experience, delays, and ratings for various airline services.

🎯 Problem Statement

Airlines collect large amounts of passenger feedback and service-related data. However, raw data can be difficult to interpret and use for decision-making.

This project analyzes passenger data to:

Understand overall passenger satisfaction.
Identify factors that influence customer satisfaction.
Analyze satisfaction across different passenger groups.
Study the impact of flight delays and travel characteristics.
Identify areas where airline services can be improved.
🎯 Project Objectives
Clean and prepare the airline passenger dataset.
Analyze passenger demographics and travel characteristics.
Measure overall passenger satisfaction.
Compare satisfaction across different classes and travel types.
Analyze service ratings and identify important service areas.
Study the relationship between flight delays and satisfaction.
Create an interactive Power BI dashboard.
Generate descriptive, diagnostic, predictive, and prescriptive insights.

📊 Analysis Types
1. Descriptive Analysis

Descriptive analysis explains what happened in the dataset.

It summarizes passenger satisfaction, demographics, travel classes, flight distances, delays, and service ratings.

2. Diagnostic Analysis

Diagnostic analysis helps understand why something happened.

It examines factors such as delays, travel class, type of travel, and individual service ratings to identify factors associated with passenger satisfaction.

3. Predictive Analysis

Predictive analysis uses the patterns found in the data to understand what may happen in similar situations.

For example, passengers experiencing better service ratings and fewer delays may show higher satisfaction levels.

4. Prescriptive Analysis

Prescriptive analysis suggests possible actions based on the findings.

Airlines can focus on improving lower-rated services, reducing delays, improving online services, and enhancing the overall passenger experience.
